# MyPrompt

A lightweight, local-first library for saving, organizing, and reusing AI prompts.

## MVP

- Create, edit, and delete prompts
- Search prompts by title, content, category, and tags
- Filter by category and favorites
- Copy prompts with one click
- Import and export prompts as JSON
- Store data in your browser with `localStorage`

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy to GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save. After deployment, the site will be available at `https://bitshadow.github.io/myprompt/` unless you configure a custom domain.

## Data and privacy

This starter stores prompts in the current browser only. Data does not sync between browsers or devices. Use JSON export for backups.
